前言：本文档用于预览 Notebook 项目中的所有离线字体，包括 Inter 常规/Display、JetBrains Mono 等宽字体 像素字体。所有字体均通过 fonts.css 加载，无需联网即可使用。

注意事项：Inter 是纯西文字体，中文部分会自动回退至系统字体。如果需要统一中文字体，可后续添加思源黑体或霞鹜文楷，只需在 fonts.css 中添加对应的 @font-face 规则即可。
// 代码示例：中英文混排的等宽效果 function greet(name: string): string { return `你好，${name}！Hello, ${name}!`; } console.log(greet("世界")); // 输出：你好，世界！Hello, 世界!
